# Homepage editorial switch and Event Headquarters video release

Approved for production by the user on October 12, 2026.

This release includes the automatic homepage switch introduced in 62d3a1e3 and Event Headquarters video support introduced in dcc03afd, rebuilt on current main to include subsequent scheduled content refreshes.

- An active Event Headquarters hides the regular homepage Pulse card, alert strip and freshness badges.
- Ending an event keeps older regular Pulse posts hidden until a regular post is newly published or edited.
- The full Pulse archive remains accessible in all modes.
- Event Headquarters supports a main video and mixed image/video galleries. Clicking a video opens playback controls; closing the viewer stops playback.
- The composer accepts image and video gallery uploads and previews selected local videos.
- Automatic custom-domain assignment must remain disabled. Verify the staged production build before manually promoting this approved release.
